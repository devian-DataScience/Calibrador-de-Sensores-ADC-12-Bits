# Calibrador-de-Sensores-ADC-12-Bits
Este projeto implementa um calibrador de sensores ADC 12 Bits utilizando as filosofias da Programação Orientada ao Objeto e conceitos básicos de álgebra linear como a solução por mínimos quadrados e cálculo de matrizes de projeção sobre subespaços vetoriais gerados pelas colunas linearmente indenpendentes de uma matriz de coeficientes.
